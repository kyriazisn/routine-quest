# 01 — Product Brief & User Stories

Status: **Draft — προς έγκριση**

## 1. Πρόβλημα

Οι πρωινές και βραδινές ρουτίνες με παιδιά 4–7 ετών καταλήγουν σε συνεχείς λεκτικές υπενθυμίσεις («πλύνε τα δόντια», «ντύσου»). Τα παιδιά αυτής της ηλικίας δεν διαβάζουν, οπότε οι λίστες και οι εφαρμογές με κείμενο δεν δουλεύουν. Οι οθόνες είναι επίσης κάτι που οι γονείς θέλουν να περιορίσουν.

## 2. Λύση

Μια φυσική συσκευή χωρίς οθόνη, με 4 μεγάλα κουμπιά. Κάθε κουμπί έχει εικονίδιο και χρώμα και αντιστοιχεί σε ένα βήμα ρουτίνας. Μια ρουτίνα είναι ένα «quest».

- Το παιδί πατά το κουμπί όταν ολοκληρώσει ένα βήμα.
- Παίρνει άμεσο feedback με φως και ήχο.
- Η πρόοδος φαίνεται σε ένα LED ring.
- Ο γονέας λαμβάνει push ειδοποίηση στο κινητό (PWA).

## 3. Χρήστες

| Ρόλος | Ανάγκες | Αλληλεπίδραση |
|---|---|---|
| Παιδί 4–7 | Απλότητα, άμεση επιβράβευση, αίσθηση ελέγχου | Μόνο χρώμα, εικονίδιο, ήχος, φως. Καθόλου κείμενο |
| Γονέας | Λιγότερο nagging, ορατότητα, έλεγχος | PWA: setup, ρουτίνες, ειδοποιήσεις, rewards |

## 4. MVP scope

### Περιλαμβάνεται

**Hardware**

| Στοιχείο | Επιλογή |
|---|---|
| MCU | ESP32-S3-WROOM-1 |
| Κουμπιά | 4× arcade 30mm |
| LEDs | 1× WS2812 ανά κουμπί + ring 12 LEDs |
| Ήχος | Piezo buzzer |
| Τροφοδοσία | USB-C 5V |

**Λειτουργίες**
- Πρωινή και βραδινή ρουτίνα (έως 4 βήματα η καθεμία), κάθε ρουτίνα με χρονικό παράθυρο.
- Wi-Fi provisioning μέσω BLE.
- Offline buffering των πατημάτων.
- Push ειδοποιήσεις στον γονέα: βήμα ολοκληρώθηκε, ρουτίνα ολοκληρώθηκε, ρουτίνα έληξε ανολοκλήρωτη.
- XP, streak και rewards που εγκρίνει ο γονέας (βλ. `02-game-design.md`).
- 1 παιδί ανά συσκευή, 1 ή περισσότεροι γονείς ανά οικογένεια.
- Signed OTA firmware updates με rollback.

### Ρητά εκτός MVP

| Feature | Λόγος |
|---|---|
| Οθόνη | Τα παιδιά δεν διαβάζουν. Αυξάνει κόστος και κατανάλωση |
| Μικρόφωνο ή κάμερα | Privacy (GDPR για παιδιά). Δεν χρειάζεται |
| Μπαταρία Li-ion | Κίνδυνος ασφάλειας και πιστοποίησης σε παιδικό προϊόν |
| SIM ή cellular | Κανόνας MVP: μόνο Wi-Fi |
| Κουμπί SOS ή «κάλεσε γονέα» | Η Wi-Fi συσκευή δεν εγγυάται παράδοση μηνύματος. Ένα τέτοιο κουμπί θα έδινε ψευδή αίσθηση ασφάλειας |
| Πολλά παιδιά ανά συσκευή | Περιπλέκει το UX για ηλικία 4–7 |
| Native iOS/Android app | Η PWA με Web Push αρκεί για το MVP |

## 5. Ορισμός επιτυχίας (pilot, 10–20 οικογένειες, 4 εβδομάδες)

| Μετρική | Στόχος |
|---|---|
| Ρουτίνες ολοκληρωμένες χωρίς λεκτική υπενθύμιση (self-report γονέα) | ≥ 70% μετά την εβδομάδα 2 |
| Χρόνος setup (unboxing → πρώτο quest) | < 5 λεπτά |
| Latency πάτημα → push (online) | p95 < 5 s |
| Feedback στη συσκευή μετά από πάτημα | < 100 ms, και offline |
| Ενεργές οικογένειες την εβδομάδα 4 | ≥ 60% |

## 6. User stories

Μορφή: *Ως <ρόλος>, θέλω <ενέργεια>, ώστε <όφελος>.*

### Παιδί

**C1 — Άμεσο feedback**
Ως παιδί, όταν πατάω ένα κουμπί, θέλω να ακούω ήχο και να βλέπω το κουμπί να ανάβει, ώστε να ξέρω ότι «μέτρησε».

Αποδοχή:
- Ηχητικό και φωτεινό feedback σε < 100 ms.
- Λειτουργεί χωρίς Wi-Fi.

**C2 — Πρόοδος quest**
Ως παιδί, θέλω να βλέπω πόσα βήματα μου μένουν, ώστε να ξέρω πότε τελείωσα.

Αποδοχή:
- Το ring γεμίζει αναλογικά με τα βήματα.
- Στο τελευταίο βήμα παίζει animation νίκης και μελωδία.

**C3 — Undo**
Ως παιδί, αν πατήσω κατά λάθος, θέλω να μπορώ να το διορθώσω.

Αποδοχή:
- Παρατεταμένο πάτημα ≥ 2 s σε κουμπί που έχει ήδη πατηθεί → undo με χαρακτηριστικό ήχο.
- Το undo στέλνεται στο backend.

**C4 — Τίποτα να «χαλάσει»**
Ως παιδί, αν πατάω τυχαία κουμπιά εκτός ρουτίνας, δεν θέλω να συμβαίνει τίποτα τρομακτικό.

Αποδοχή:
- Εκτός παραθύρου ρουτίνας, το πάτημα δίνει μόνο ήπιο «ύπνος» animation.
- Δεν καταγράφεται event προόδου.

### Γονέας

**P1 — Setup**
Ως γονέας, θέλω να συνδέσω τη συσκευή στο Wi-Fi από το κινητό χωρίς τεχνικές γνώσεις.

Αποδοχή:
- BLE provisioning από την PWA (Web Bluetooth). Fallback: SoftAP σε browsers χωρίς Web Bluetooth (π.χ. iOS Safari).
- Τα Wi-Fi credentials **δεν** περνούν από το backend.

**P2 — Ρουτίνες**
Ως γονέας, θέλω να ορίσω πρωινή και βραδινή ρουτίνα με 1–4 βήματα, εικονίδιο ανά κουμπί και χρονικό παράθυρο ανά ημέρα εβδομάδας.

**P3 — Ειδοποιήσεις**
Ως γονέας, θέλω ειδοποίηση όταν ολοκληρώνεται ένα βήμα ή όλη η ρουτίνα.

Αποδοχή:
- Ρυθμίζεται ανά ρουτίνα: κάθε βήμα / μόνο ολοκλήρωση / σίγαση.
- Υπάρχουν quiet hours.

**P4 — Ανολοκλήρωτη ρουτίνα**
Ως γονέας, θέλω ειδοποίηση αν η ρουτίνα δεν ολοκληρωθεί μέσα στο παράθυρο.

**P5 — Ιστορικό**
Ως γονέας, θέλω να βλέπω streak, XP και ιστορικό 7 ημερών.

**P6 — Rewards**
Ως γονέας, θέλω να ορίζω και να εγκρίνω rewards, ώστε η συσκευή να μην «υπόσχεται» μόνη της πράγματα στο παιδί.

**P7 — Παύση**
Ως γονέας, θέλω «ημέρα εκτός» (αρρώστια, διακοπές) που δεν σπάει το streak.

**P8 — Διαγραφή**
Ως γονέας, θέλω να διαγράψω όλα τα δεδομένα και να κάνω factory reset.

Αποδοχή:
- Hard delete στο backend εντός 30 ημερών.
- Το reset γίνεται και από τη συσκευή με συνδυασμό κουμπιών ≥ 10 s.

**P9 — Δεύτερος γονέας**
Ως γονέας, θέλω να προσκαλέσω τον/την σύντροφο, ώστε να λαμβάνει κι εκείνος/η ειδοποιήσεις.

### Σύστημα

**S1 — Offline buffering**
Αν πέσει το Wi-Fi, τα events αποθηκεύονται τοπικά (≥ 500 events) και συγχρονίζονται αργότερα χωρίς διπλοεγγραφές (idempotent `event_id` UUID).

**S2 — Χρόνος**
Ο χρόνος συσκευής συγχρονίζεται με SNTP. Τα events φέρουν και monotonic counter για την περίπτωση που λείπει RTC.

**S3 — OTA**
Τα firmware updates είναι signed, με A/B partitions και αυτόματο rollback αν το νέο image δεν κάνει health-check.

**S4 — Device identity**
Κάθε συσκευή έχει μοναδικό `device_id` και per-device secret που παράγεται στο pairing. Υπάρχει δυνατότητα revoke από τον γονέα.

## 7. Παραδοχές προς επιβεβαίωση

- **A1.** Οι γονείς δέχονται PWA αντί για native app. Στο iOS η Web Push απαιτεί «Add to Home Screen», οπότε το onboarding πρέπει να το καθοδηγεί.
- **A2.** 4 κουμπιά αρκούν για τις περισσότερες ρουτίνες στις ηλικίες 4–7.
- **A3.** Το οικιακό Wi-Fi είναι 2.4 GHz-capable. Ισχύει για σχεδόν όλα τα routers, αλλά τα mesh δίκτυα με κοινό SSID 2.4/5 GHz θέλουν έλεγχο.
